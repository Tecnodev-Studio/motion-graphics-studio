This project's own code is Apache License 2.0 (see LICENSE and NOTICE). It uses these free tools; check each licence if you redistribute them.

| Component | Role | Licence (verify upstream) |
|---|---|---|
| FFmpeg / ffprobe | encode, mux, silence detection | LGPL/GPL depending on the build (you can use it to make your own videos freely) |
| NumPy, SciPy | arrays, audio DSP | BSD-3-Clause |
| OpenCV (opencv-python-headless) | drawing, transforms | Apache-2.0 (wheels bundle an LGPL FFmpeg) |
| Pillow (with libraqm) | text shaping incl. Arabic/RTL | HPND (MIT-like) |
| DejaVu Sans (fallback font, if present on your OS) | text | Bitstream Vera licence (free) |

Sound effects are synthesized by code (no samples, nothing to license). The robot mascot is drawn by code. Fonts, photos, music and voices you add are **yours to license**: prefer SIL-OFL fonts (Noto, Cairo), CC0/public-domain media, or your own recordings.
