# Example profile: Arabic tech Shorts channel (Iraqi dialect)

Copy and edit for your own channel; the agent reads files in `profiles/` that match the user.

- **Language**: replies to the user in simple Iraqi Arabic, short (mobile reader). Scripts in pure Iraqi dialect, no Gulf words. Prefer: هسه، اكو، شكو، حيل، مو، شلون، شنو، اكلك، بلا. Avoid: دايماً، وايد، إيوه. Write phrases the way they are said (اكلك، اكول) in subtitles; keep Latin brand names as is.
- **Subtitles**: plain, no diacritics, no decoration; wording rules from the user (e.g. always "الذكاء الاصطناعي", never "الذكاء" alone) via `set_captions(fix=...)`.
- **Voice**: the user brings an Iraqi voice-over file; for text-to-speech add phonetic spelling for foreign names; the letter گ marks the Iraqi qaf.
- **Style**: cream & copper (see `docs/style-analysis.md`) or the forest brand palette; robot presenter in a corner, animated to the topic (lips, expressions, pointing, walking between items); a small brand tag at the top and a thin progress bar.
- **Honesty**: channel brand = tests and honest pros/cons; say what was not tested; no fake trends; no personal details in scripts.
- **Closing line (series)**: set per channel, e.g. "تابعونا لمزيد من الشروحات على قناتنا".
