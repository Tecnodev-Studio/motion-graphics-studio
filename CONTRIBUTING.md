# Contributing

Thanks for helping. Rules:
- Keep it **free and offline**: no paid services, no API keys, no network calls at render time.
- Run `python tests/selftest.py` before opening a pull request; add a check for anything new.
- A new component = a pure drawing function in `mgs/components.py` (time `t` in, drawing out), plus a line in the self-test and `docs/components.md`.
- Don't commit media you don't own (photos, music, fonts, other companies' logos).
- By contributing you agree your contribution is licensed under Apache-2.0 like the rest of the project.
