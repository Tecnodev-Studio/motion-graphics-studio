# Self-review before delivering (free fixes only)

Score each 0-10, note defects with timestamps, fix, re-render only what changed.
1. **Hook** - clear claim in <3 s, visual motion in the first second.  2. **Pacing** - something new every 2-3 s, no dead air, scene changes hide in pauses.  3. **Clarity** - one idea per scene, text readable at phone size (>= 44 px body at 1080 wide), nothing clipped.  4. **Design** - consistent palette/type, hierarchy (title > cards > captions), alignment, no overlaps.  5. **Safe areas** - key content inside `K.safe_area()`; captions not under platform UI.  6. **Contrast** - >= 4.5:1 (the `check` command warns).  7. **Audio** - voice clear, SFX subtle and on the visual, music ducked, loudness ~ -14 LUFS, no clipping.  8. **Sync** - captions and visuals match the spoken words; audio/video lengths equal.  9. **Accuracy & honesty** - facts verified, illustrative items labelled, no fabricated examples.  10. **Accessibility** - captions on, SRT/VTT exported, no flashing > 3 times/s (limit `fx.flash`, `glitch`).  11. **CTA & ending** - one clear ask, held long enough to read.  12. **Technical** - right size/fps, file < 250 MB, plays on a phone.
Publish decision: >= 80 total and no item below 6, else fix the lowest items first. Report the score and defect list to the user in plain words.
