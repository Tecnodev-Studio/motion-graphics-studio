# Script craft

- **Hook (0-3 s)**: a concrete claim, a number, a contradiction or a direct question. No greetings, no "in this video". If the claim could be false (e.g. "app X can't do Y"), verify it first.
- **Structure**: hook -> one-sentence idea -> 2-4 points (each = one visual) -> one honest limitation -> short conclusion -> CTA (a question for comments works better than "like and subscribe").
- **Phrases**: one idea per comma/period, 3-12 words; these become scenes and captions. Read aloud; cut anything you stumble on.
- **Length**: decide with the user. Common targets 30-60 s (Shorts/Reels). Platform limits change - check the current rules.
- **Honesty**: never say "I tested" unless they did; no invented numbers/examples; label illustrative graphics; say what you could not verify; no medical/legal/financial claims without a source. State trend claims only with the source you actually saw.
- **Language/dialect**: ask which dialect; write the way people speak (see `profiles/arabic-tech-channel.md` for an Iraqi example). Keep Latin brand names unchanged; for text-to-speech, hard words may need phonetic spelling.
- **Subtitles**: the phrase text, plain (no diacritics unless wanted), the user's own spelling; apply their wording rules in `caption fix`. If audio and text differ, tell them.
- **Series**: keep the same closing line and visual identity across videos if the user has one.
